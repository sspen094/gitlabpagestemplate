# Modules

Ownership areas of the product. Slices deliver features inside a module.

| Module id | Purpose | Features |
|-----------|---------|----------|
| platform | App host, Vite build, GitHub Pages | [app-scaffold](../../modules/platform/features/app-scaffold/README.md) |
| text | Developer-authored copy via `t()` | [t-lookup](../../modules/text/features/t-lookup/README.md) |

Later slices add modules for page blocks, navigation, and Sheets-backed content.
